The Fallback

The flat star chart. It is served to every phone and to any machine that cannot run the scene, and it is one click from the scene for anyone who would rather read a list. It carries every Client, every Project, every field and every Notable, at full length.

Both widths are rendered below, as two framed viewports. The layout genuinely differs between them — the plate reprojects, the index changes from a table to a stacked list, and the record's field rows stack. Nothing is dropped at either width.

The records

SNCF

Client referential — MDM replacement

The Oracle MDM cost twice: an expensive licence, and a team employed full-time to correct the data it produced. Replacing it meant rebuilding a mature product's behaviour with no specification to work from — documentation was absent or years stale, so the incumbent's real rules had to be recovered from the system itself.

The house standard was Spring on a dedicated external Tomcat, on ageing on-premise infrastructure. I argued for Spring Boot with embedded Tomcat instead — the better fit, and the furthest the client would go. With a mostly junior team on a critical system, a from-scratch rebuild on a current stack was also the one chance they'd get to learn one.

Condensed

The plate is the chart; the table is the same chart in reading order. Time is the horizontal axis, running backward left to right, which is the scene's scroll direction turned into position — this is why the Fallback is the better surface for navigating by date. The ring carries the Deep/Shallow signal on the plate; the same ring is drawn per row in the table's marker column and named as a real column value, so a screen reader answers the M2 gate's second clause from the table alone.

Condensed

The projection transposes rather than scaling. Time runs down the page — present at the top — so the plate agrees with the phone's own scroll direction and gets the axis it has room for. Each Client becomes a stem, labels run horizontally into the width, and the ring is drawn at the same 2.2 ratio it has on the desktop plate. The index becomes a stacked list with the ring in a fixed left gutter; field rows stack their labels above their values; the Notable is set at 15px because the measure narrowed, and not one word of it is cut.
