Direction 04

Almanac

This direction borrows the register of a printed star catalogue: every body carries a designation, magnitude is drawn as an actual graded mark rather than implied, and a real legend sits inside the plate instead of floating as interface chrome. The ground is warm graphite rather than blue-black, so it reads as ink photographed off paper, and a single desaturated rust behaves like a catalogue's second printing plate — reserved for designations, the magnitude scale and the current entry. Serif prose and small-caps grotesque apparatus give the reading layer the feel of a well-set reference work, which is exactly the invitation a technical reader responds to.

Magnitude is drawn to a scale the legend actually shows, so a visitor can measure engagement weight off the chart rather than guess at it. The ecliptic doubles as the time axis, graduated in years and running backward left-to-right, which places the scroll's direction in the first frame without a single instruction.

SNCF · 2016—2024

Client referentialMDM replacement

The Oracle MDM cost twice: an expensive licence, and a team employed full-time to correct the data it produced. Replacing it meant rebuilding a mature product's behaviour with no specification to work from — documentation was absent or years stale, so the incumbent's real rules had to be recovered from the system itself.

The house standard was Spring on a dedicated external Tomcat, on ageing on-premise infrastructure. I argued for Spring Boot with embedded Tomcat instead — the better fit, and the furthest the client would go. With a mostly junior team on a critical system, a from-scratch rebuild on a current stack was also the one chance they'd get to learn one.
